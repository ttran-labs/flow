# explainer

## 1. Lead with a picture

Open with a graph, diagram, flow, or an interactive or game-like example,
not a paragraph. Reference the thinking-graph neurons the ideas come from.

Done when: the first thing the reader sees is a diagram or an example, and
each idea names its neuron, or the page says the neurons tools were
unreachable.

## 2. Build the page

When the explainer becomes HTML, it is:

- interactive: toggles, animated flows, node graphs where one flow can be
  isolated;
- self-contained: one file that opens offline;
- grounded: every claim links its `file:line` or its source;
- crafted to the high-end-visual-design skill's standard;
- full viewport width: no centered narrow column, no max-width on
  paragraphs.

Done when: every item above holds when the page is opened in a browser.

## 3. Save it

Save it to the project vault with the obsidian-vault skill, with a markdown
stub when the file is HTML.

Done when: the file and its stub are in the vault.
