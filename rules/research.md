# Research — never answer blurry from memory

Skills: research, find-docs.

Whenever anything is blurry, unclear or unknown (a concept, a tool, an API,
a domain fact, a best practice, a version behaviour), resolving it with the
research tools is a must, never optional:

- The research skill: investigate the open question against high-trust
  primary sources and capture the findings.
- The find-docs skill: any library, framework, SDK, API, CLI tool or cloud
  service, even a well-known one, even when you think you know the answer.
  Training data is stale; never answer those from memory. Prefer it over
  web search for library docs.
- Web search and fetch back these up when primary docs are not enough.

Guessing where these tools apply is a violation. Applies to every agent,
main or spawned. Full flow: the research loop in the Flow graph in
~/.claude/CLAUDE.md.
